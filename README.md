# Smart-Pomodoro-Clock
SPC-34 is a Pomodor clock used for study sessions and to improve the quality of your sessions.
It is powered by Arduino-Uno micrcontroller and controlled with an ultrasonic sensor.
first version: basic with25/5 study loops
second version: more advanced,gesture controls, a variety of options.
third version: obtains the feature of automatic study loops added to the 2 second version
More versions of the clock will be out soon.
recommendation: use a rechargable batter, such as power bank.
